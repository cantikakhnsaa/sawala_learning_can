# Sawala Learning Project

Project pembelajaran JavaScript Modern untuk kegiatan PKL Sawala.

## Tujuan

Project ini dibuat untuk mempelajari dasar-dasar JavaScript dan JavaScript Modern dari awal, serta menerapkannya melalui beberapa latihan dan mini project.

## Materi yang Dipelajari

- Variabel dengan `let` dan `const` 
- Tipe data
- `if`, `else if`, dan `else`
- Function
- Parameter, argument, dan `return`
- Operator perbandingan
- Array
- Object
- Array of Object
- `console.log()`
- Looping dengan `for`
- `forEach()`
- `map()`
- `filter()`
- `find()`
- `reduce()`
- Destructuring
- Spread operator
- ES Modules dengan `import` dan `export`
